拾光 iOS 1.8.0 P5 更新说明

本版目标：让 iOS 的主要按钮和操作层级继续贴近 Android 版，并解决“回到那天”浏览、删除手势和放大返回体验。

1. 上滑删除动画
- 单张浏览和“回到那天”网格中，上滑时会显示“↑ 上滑到垃圾桶”提示。
- 随上滑进度，右下角垃圾桶会放大形成吸附反馈。
- 达到删除阈值后，照片/缩略图会缩小并飞向垃圾桶，再加入待删除列表。

2. “回到那天”性能与选中状态
- 将浏览状态 JSON 的写盘从主线程移到串行后台队列，减少上滑标记时的卡顿。
- 网格上滑完成后只更新当前 cell 的待删除标记，不再每次 reloadData 全量刷新。
- 当前触摸/双指放大的照片增加蓝色边框。
- 双指放大进入单图增加轻微放大 + 淡入过渡。

3. 黑色背景修复
- 进入“回到那天”后隐藏底层单张照片视图。
- 页面和网格背景强制为纯黑色，避免底层某张照片透出来。

4. 放大“回到那天”照片后的返回逻辑
- 此模式取消 1/1、上一张、返回、下一张等底部按钮。
- 两种返回方式：
  a) 从屏幕左边缘向右滑，返回“回到那天”网格；
  b) 双指向内缩小到阈值，返回“回到那天”网格。
- 在“回到那天”网格中，从屏幕左边缘向右滑，继续返回随机单张浏览。
- 这对应 Android 的 Back 层级：放大单图 -> 当天网格 -> 随机单张。
- iOS 不实现“返回即退出 App”，因为 iOS 不建议应用主动退出。

5. 保留功能
- 动态照片自动播放 / 不播放设置保留。
- 相册权限独立入口和诊断页保留。
- 待删除集中确认、撤销、回看已标记逻辑保留。

安装/构建：
将压缩包完整上传到原 GitHub 仓库（覆盖同名项目文件，保留 .github/workflows），运行 Build iPhone IPA 工作流即可。
首次打开授权页应显示“拾光 · P5”；菜单显示“拾光 · iOS 1.8.0 · P5”。

验证：
- 已通过项目资源/引用、Info.plist、SceneDelegate、隐私清单、图标等静态检查。
- 当前环境没有 Xcode/UIKit SDK，因此未做 Swift 真机编译、模拟器或 iPhone 真机手势验证。
